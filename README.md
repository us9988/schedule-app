## ✨ Key Features
* **간편한 일정 등록**
* **오늘 일정 푸시 알림** 
* **캘린더 뷰**
* **다크 모드 지원**
* **일정 검색**

## 🛠 Tech Stack

* **Language:** Kotlin
* **UI:** Jetpack Compose (Material3)
* **Architecture:** MVVM Pattern, Repository Pattern
* **DI:** Hilt
* **Async:** Coroutines, Flow
* **Local DB:** Room Database
* **Background:** WorkManager
