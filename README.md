## ✨ Key Features
* **간편한 일정 등록**
* **학사 일정 불러오기**
* **오늘 일정 푸시 알림** 
* **캘린더 뷰**
* **다크 모드 지원**
* **일정 검색**

## 🛠 Tech Stack

* **Language:** Kotlin
* **UI:** Jetpack Compose (Material3)
* **Architecture:** MVVM
* **DI:** Hilt
* **Async:** Coroutines, Flow
* **Local DB:** Room Database
* **Remote DB:** FireStore
